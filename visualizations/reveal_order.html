Reveal order

In which order does MDLM decoding commit the positions? Each cell is the average step at which a position was committed, over 300 simulated runs, using the real block windows, scheduler counts and top-k. Compare two settings.

The model is synthetic: confidence is higher next to already-known tokens (locality), optionally very high in the last quarter of the canvas. It shows what the sampler does with such scores, not how a trained model behaves.
